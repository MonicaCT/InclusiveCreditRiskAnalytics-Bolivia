# Accessibility Checklist

## Layout

- Use high contrast between text and background.
- Keep KPI cards readable on 1366px desktop screens.
- Avoid overloading any page with more than six main visuals.
- Use consistent visual order: KPIs, trends, comparison, notes.

## Text

- Use plain English labels.
- Always display units.
- Avoid unexplained abbreviations.
- Add short limitation notes where interpretation risk is high.

## Color

- Do not rely on color alone for risk states.
- Use labels for Controlled, Watch and Elevated states.
- Use the shared report theme.

## Navigation

- Provide a page navigation bar.
- Keep Back to Portfolio available in the published repository page, not inside the `.pbix`.

## Privacy

- Do not expose raw records in tables.
- Do not include personal identifiers.
- Do not publish local file paths in report text boxes.
