# Power BI notes

No `.pbix` file is distributed in this repository. This folder documents a lightweight Power BI implementation that can be built from the public processed outputs without exposing raw operational workbooks.

Recommended public inputs:

- `data/processed/inclusion_metrics_panel.csv`
- `data/processed/branch_shares_panel.csv`
- `outputs/tables/model_backtesting.csv`
- `outputs/tables/stress_test_scenarios.csv`
- `outputs/tables/territorial_balance_metrics.csv`

The dashboard specification mirrors the GitHub Pages dashboard and keeps the same privacy boundary: branch-level or aggregate indicators only.
