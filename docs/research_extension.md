# Research Extension Plan

## Doctoral Motivation

This repository can be extended from a portfolio analytics project into an applied development economics research design. The current data show branch-level financial inclusion dynamics. A doctoral version would test whether branch expansion changes access to formal credit and whether that access is associated with local development outcomes.

## Candidate Research Question

Does the expansion of microfinance branch access improve formal credit inclusion and reduce territorial inequality in underserved urban markets?

## Testable Hypotheses

1. Branch expansion increases formal credit outreach measured by clients reached and active portfolio.
2. Credit outreach becomes less territorially concentrated after the second branch matures.
3. Rapid portfolio growth is sustainable only when mora remains controlled.
4. Credit access effects are stronger in zones with higher initial financial exclusion or poverty.

## Data Needed For A Causal Study

| Data layer | Purpose |
|---|---|
| Branch geolocation | Define treated and comparison catchment areas. |
| Municipal or neighborhood poverty maps | Connect credit access with poverty and inequality. |
| Household or enterprise surveys | Measure welfare, income, business growth, and resilience. |
| Credit registry or client-level anonymized records | Study access, repayment, and product depth. |
| Macro controls | Separate portfolio dynamics from broader economic cycles. |

## Possible Identification Strategies

### Event Study

Use branch opening or branch maturation dates as events and estimate pre/post changes in outreach, portfolio, and mora.

### Difference-in-Differences

Compare areas exposed to branch expansion with similar areas not exposed during the same period.

### Synthetic Control

Construct a weighted comparison unit from similar branches or areas to estimate counterfactual portfolio and client growth.

### Hierarchical Forecasting

Model branch-level portfolio trajectories with partial pooling to compare mature and new branches while preserving uncertainty.

## Empirical Caution

The existing repository does not contain poverty outcomes. It is appropriate for a financial inclusion and responsible growth analysis. Poverty and inequality impacts require additional socioeconomic data and a credible identification strategy.

## Portfolio Value

For doctoral applications, this shows research discipline: clear question, measurable proxies, limitations, and a path toward causal inference.

For senior data analyst roles, this shows production discipline: data cleaning, KPI design, model validation, privacy review, and executive communication.
